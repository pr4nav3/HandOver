How to use it

  1. 01Prop this phone up so the back camera sees the learner's hands.
  2. 02Tap Start Camera.
  3. 03Start the lesson on the learner's screen. This screen shows the step and Next.

Frames go to the hub on this network, which sends them to the AI model for each check. The hub never saves them.

Keep this page open and on screen. If the screen still dims, turn off Auto-Lock in Settings, Display and Brightness.
