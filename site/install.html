HandOver for Mac

Apple silicon · macOS 14 or later

Download for MacAll release files ↗
  1. Open the disk image and drag HandOver to Applications.
  2. If macOS blocks this research build, open System Settings → Privacy & Security → Open Anyway.
  3. Open HandOver and scan its pairing code with the phone app.

The current public build is not notarized. The release page includes its checksum.

Phone camera and Meta glasses bridge

HandOver for iPhone

iOS 18 or later · Xcode install

Open the Xcode projectBuild instructions ↗
  1. Clone the repository on a Mac, generate the Xcode project, and select your free Personal Team.
  2. Plug in the iPhone, choose it as the destination, and press Run.
  3. For Ray-Ban Meta video, pair the glasses in Meta AI and enable Developer Mode there.

There is no App Store or TestFlight release yet. An Xcode build is the honest install path; a random IPA would not install without your own signing.

Phone camera and wearable bridge

HandOver for Android

Android 10 or later

Download APKBuild from source ↗
  1. Download and open the APK.
  2. Allow installs from your browser when Android asks.
  3. Open HandOver and scan the code shown on the Mac.

The current APK is release-optimized but signed with the project’s development key. Replace it with a stable release key before broad distribution.
